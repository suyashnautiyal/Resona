# Resona — AI Voice Agents Landing Page

A responsive SaaS landing page for **Resona**, an AI voice-agent product. Built as part of a front-end development assignment.

## Tech Stack

- **React 19** (JavaScript) + **Vite 8**
- **Tailwind CSS v4** (via `@tailwindcss/vite`)
- No backend — the demo form simulates submission

## Setup

```bash
git clone <your-repo-url>
cd resona
npm install
npm run dev
